# 지뢰찾기

Windows 95/98의 클래식한 화면으로 즐기는 웹 지뢰찾기입니다. 초급, 중급, 고급 난이도를 제공하며 첫 클릭 안전 규칙, 깃발, flood fill, chording, 타이머, 승패 연출을 구현했습니다.

## 게임 소개

왼쪽 클릭으로 칸을 열고, 오른쪽 클릭으로 깃발을 꽂습니다. 숫자 칸을 다시 클릭하면 주변 깃발 수가 숫자와 일치할 때 인접 칸을 한 번에 엽니다. 모든 안전 칸을 열면 승리하고, 지뢰를 열면 패배합니다.

## 어떻게 만들었나요

PRD의 요구사항을 먼저 게임 상태, 입력 처리, 화면 연출, 검증 단계로 나눈 뒤 Plan을 작성했습니다. 구현은 별도 빌드 도구 없이 [index.html](./index.html) 하나에 Vanilla JavaScript와 CSS를 담는 방식으로 진행했습니다.

## freeform 버전과 비교했을 때

freeform 버전은 핵심 조작을 빠르게 확인하는 데 초점을 맞추고, prd 버전은 세 난이도, 첫 클릭 안전, chording, 잘못된 깃발 표시, 컨페티와 클래식 bevel UI까지 요구사항을 기준으로 구현하는 것을 목표로 합니다. 기능 누락 여부를 확인하기 쉽기 때문에 prd 버전을 기준으로 선택합니다.

## 실행 방법

저장소의 `index.html`을 브라우저로 직접 열면 실행됩니다. 별도 설치나 빌드 명령은 필요하지 않습니다. GitHub Pages에 배포할 때는 `gh-pages` 브랜치의 루트에 이 파일을 둡니다.

## 커스터마이징한 부분

초급(9×9, 지뢰 10개), 중급(16×16, 지뢰 40개), 고급(30×16, 지뢰 99개) 선택 기능을 추가했습니다. 또한 첫 클릭 주변 보호, flood fill, chording, 999초 타이머, 표정 상태 버튼, 승리 컨페티, 패배 시 잘못된 깃발 X 표시와 모바일 가로 스크롤을 포함했습니다.
