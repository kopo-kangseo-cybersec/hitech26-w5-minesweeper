# 클래식 지뢰찾기

Windows 95/98 스타일의 UI로 즐기는 브라우저용 지뢰찾기입니다. 별도 프레임워크나 빌드 과정 없이 [index.html](./index.html) 한 파일로 실행됩니다.

## 주요 기능

- 초급, 중급, 고급 난이도 선택
- 첫 클릭한 칸과 주변 8칸을 보호하는 첫 클릭 안전 규칙
- 빈 칸을 자동으로 확장하는 flood fill
- 열린 숫자 칸을 다시 눌러 주변 칸을 여는 chording
- 깃발 수를 반영하는 남은 지뢰 카운터
- 첫 클릭부터 게임 종료까지 동작하며 999초에서 멈추는 타이머
- 승리 시 자동 지뢰 표시와 컨페티 애니메이션
- 패배 시 전체 지뢰 공개, 폭발 칸 강조, 잘못된 깃발 `X` 표시
- 키보드 포커스 표시와 `prefers-reduced-motion` 대응
- 작은 화면에서 보드가 가로로 스크롤되는 반응형 레이아웃

## 난이도

| 난이도 | 보드 | 지뢰 |
| --- | ---: | ---: |
| 초급 | 9 x 9 | 10 |
| 중급 | 16 x 16 | 40 |
| 고급 | 30 x 16 | 99 |

## 조작 방법

- **왼쪽 클릭**: 칸을 엽니다. 빈 칸을 열면 인접한 안전 칸이 연쇄적으로 열립니다.
- **오른쪽 클릭**: 닫힌 칸에 깃발을 꽂거나 제거합니다. 브라우저 컨텍스트 메뉴는 표시되지 않습니다.
- **열린 숫자 칸 다시 클릭**: 주변 깃발 수가 숫자와 같을 때 깃발이 없는 인접 칸을 한 번에 엽니다.
- **스마일 버튼**: 현재 난이도로 게임을 다시 시작합니다.
- **난이도 선택**: 선택 즉시 새 보드를 만듭니다.

안전한 칸을 모두 열면 승리하고, 지뢰를 열면 패배합니다. 게임이 시작되기 전에는 보드에 지뢰를 배치하지 않으므로 첫 클릭으로 즉시 패배하지 않습니다.

## 구현 방식

게임 상태와 난이도별 설정은 Vanilla JavaScript로 관리합니다. 첫 클릭 후 보호 영역을 제외한 칸을 섞어 지뢰를 배치하고, 각 칸의 인접 지뢰 수를 계산합니다. 보드와 상태 표시 영역은 DOM API로 렌더링하며 CSS의 `border` 효과로 클래식 Windows 베벨 UI를 재현했습니다.

이 브랜치는 PRD 요구사항을 바탕으로 구현한 버전을 배포하기 위한 `gh-pages` 브랜치입니다. `freeform` 버전과 비교해 난이도 선택, 첫 클릭 보호, chording, 승패 연출 등 요구사항을 더 완전하게 반영했습니다.

## 실행 방법

저장소 루트의 `index.html`을 브라우저로 직접 열면 됩니다.

```text
index.html
```

별도 패키지 설치나 빌드 명령은 필요하지 않습니다. GitHub Pages에서는 이 브랜치의 루트를 정적 파일 배포 대상으로 사용합니다.
