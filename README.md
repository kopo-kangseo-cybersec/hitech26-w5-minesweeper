# 지뢰찾기 (Classic Minesweeper)

Windows 95/98/2000 분위기의 클래식 UI로 구현한 싱글플레이 지뢰찾기 웹 게임입니다. 별도의 빌드 과정 없이 정적 파일만으로 실행되며, [GitHub Pages 배포본](https://leetaewon.github.io/hitech26-w5-minesweeper/)에서 바로 플레이할 수 있습니다.

## 게임 기능

전통적인 지뢰찾기의 규칙을 유지하면서 다음 기능을 제공합니다.

- 초급·중급·고급 공식 난이도 선택
- 첫 번째로 여는 칸과 주변 8칸에 지뢰가 생기지 않는 첫 클릭 안전 규칙
- 빈 칸을 여는 연쇄 오픈(flood fill)
- 깃발 표시 및 남은 지뢰 수 카운터
- 열린 숫자 칸의 주변을 한 번에 여는 chording
- 지뢰를 밟았을 때 전체 지뢰 공개 및 잘못된 깃발 표시
- 승리 시 자동 깃발 처리와 confetti 축하 효과
- 재시작 버튼, 경과 시간 표시, 반응형 보드

## 난이도

| 난이도 | 보드 | 지뢰 | 안전 칸 |
| --- | ---: | ---: | ---: |
| 초급 | 9 × 9 | 10 | 71 |
| 중급 | 16 × 16 | 40 | 216 |
| 고급 | 30 × 16 | 99 | 381 |

지뢰는 첫 클릭 순간에 무작위로 배치됩니다. 첫 클릭 칸과 실제 보드에서 유효한 주변 칸을 후보에서 제외하므로, 시작하자마자 지뢰를 밟지 않습니다.

## 조작 방법

| 입력 | 동작 |
| --- | --- |
| 마우스 왼쪽 클릭 | 닫힌 칸 열기 |
| 마우스 오른쪽 클릭 | 깃발 켜기/끄기 |
| 마우스 가운데 클릭 | 열린 숫자 칸의 chording 실행 |
| 좌·우 버튼을 누른 채 놓기 | 주변 칸을 누른 상태로 표시하고, 조건이 맞으면 chording 실행 |
| 웃는 얼굴 버튼 | 현재 난이도로 다시 시작 |
| 난이도 선택 | 선택한 난이도로 새 게임 시작 |

Chording은 열린 숫자 칸 주변의 깃발 수가 해당 숫자와 정확히 같을 때만 실행됩니다. 깃발을 잘못 표시한 상태에서 실행하면 지뢰를 열어 패배할 수 있습니다.

## 승리와 패배

- **승리:** 지뢰가 아닌 모든 안전 칸을 열면 게임이 종료되고, 남은 지뢰에 깃발이 자동으로 표시됩니다. 버튼 표정이 `😎`로 바뀌며 축하 효과가 재생됩니다.
- **패배:** 지뢰를 열면 게임이 종료됩니다. 밟은 지뢰는 빨간색으로 강조되고, 다른 지뢰는 공개되며, 지뢰가 아닌 칸에 꽂은 깃발에는 `X`가 표시됩니다. 버튼 표정은 `😵`로 바뀝니다.
- 게임이 시작되면 타이머가 1초마다 증가하고, 승리·패배 또는 999초 도달 시 멈춥니다.

## 기술 구성

- HTML: 게임 화면, 난이도 선택, 상태 메시지, 접근 가능한 grid 구조
- CSS: Windows 클래식 베벨 UI, LED 스타일 카운터, 숫자별 색상, 반응형 레이아웃
- Vanilla JavaScript: 게임 상태 관리, 지뢰 배치, 연쇄 오픈, chording, 승패 처리
- [canvas-confetti](https://www.npmjs.com/package/canvas-confetti): 승리 축하 효과(CDN)

주요 파일은 다음과 같습니다.

```text
index.html  게임 화면과 컨트롤
styles.css  레트로 UI와 반응형 스타일
game.js     게임 규칙과 이벤트 처리
guide.md    브랜치별 실습 과정과 PRD 작성 가이드
```

## 로컬 실행

저장소 루트에서 정적 서버를 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 <http://localhost:8000>을 엽니다. `index.html`을 직접 열어도 게임은 실행되지만, 정적 서버를 사용하면 배포 환경과 같은 방식으로 확인할 수 있습니다. 승리 confetti는 jsDelivr CDN 연결이 필요합니다.

## 브랜치 비교

- `freeform`: PRD 없이 자연어 요청으로 구현한 버전
- `prd`: 요구사항 문서(PRD)를 작성하고 계획을 검토한 뒤 구현한 버전
- `gh-pages`: 최종 선택한 `prd` 기반 게임을 GitHub Pages로 배포하는 버전

최종 버전은 난이도·첫 클릭 안전·chording·고전 UI·승패 연출처럼 요구사항을 확인하기 쉬운 `prd` 구현을 선택했습니다. 브랜치 제작 과정은 [guide.md](./guide.md)에서 확인할 수 있습니다.

## 현재 제외된 기능

- 사용자 지정 보드 크기와 지뢰 수
- 로컬 저장 기록 및 온라인 순위표
- 물음표 마킹
- 배경음악과 효과음
