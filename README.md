# 💣 지뢰찾기

Windows 지뢰찾기의 핵심 조작을 재현한 브라우저용 지뢰찾기 게임입니다. 초급, 중급, 고급 난이도를 선택할 수 있으며 첫 클릭과 주변 8칸은 항상 안전합니다.

## 게임 소개

좌클릭으로 칸을 열고, 우클릭으로 깃발과 물음표를 표시합니다. 숫자가 없는 영역은 자동으로 펼쳐지며, 모든 안전한 칸을 열면 승리합니다. 지뢰를 클릭하면 모든 지뢰와 잘못된 깃발이 표시되고 게임이 종료됩니다.

| 난이도 | 보드 | 지뢰 |
| --- | ---: | ---: |
| 초급 | 9 × 9 | 10 |
| 중급 | 16 × 16 | 40 |
| 고급 | 30 × 16 | 99 |

## 어떻게 만들었나요

PRD로 게임 규칙과 완료 기준을 먼저 정리한 뒤, 구현 계획에서 게임 상태, 첫 클릭 안전 영역, BFS 자동 확장, 타이머와 입력 차단을 분리했습니다. 구현은 외부 라이브러리 없이 HTML, CSS, ES6 JavaScript로 구성했습니다.

게임 상태는 JavaScript 모듈 스코프 안에서 관리하고, 셀 객체에는 행·열 위치, 지뢰 여부, 공개·깃발·물음표 상태, 주변 지뢰 수를 저장합니다.

## freeform 버전과 비교했을 때

freeform 버전이 기본적인 좌클릭, 우클릭, 재시작 흐름을 빠르게 구현하는 방식이라면, PRD 버전은 세 난이도, 첫 클릭 안전 규칙, 물음표 상태, 빈 칸 자동 확장, 숫자 칸 chord, 상태별 화면 표시까지 요구사항을 기준으로 검증할 수 있게 구성했습니다. 이번 버전은 명확한 완료 기준과 유지보수 가능한 함수 분리를 우선했습니다.

## 실행 방법

별도 설치나 빌드가 필요하지 않습니다.

1. 저장소 루트의 `index.html`을 브라우저에서 엽니다.
2. 난이도를 선택하고 보드의 첫 칸을 클릭합니다.

자세한 실습 절차와 GitHub Pages 배포 흐름은 [guide.md](./guide.md)를 참고하세요.

## 커스터마이징한 부분

- 클래식 Windows 스타일의 입체 패널과 셀 디자인
- 초급·중급·고급 난이도 버튼 선택
- 첫 클릭 및 주변 8칸 지뢰 배치 방지
- 닫힘 → 깃발 → 물음표 상태 순환
- 숫자 칸의 주변 깃발 확인 후 자동 공개(chord)
- 좌우 동시 클릭 시 주변 셀이 눌렸다가 복귀하는 시각 피드백
- 상태에 따른 재시작 버튼 표정과 승리·패배 메시지
- 좁은 화면에서 보드를 가로 스크롤할 수 있는 반응형 레이아웃
