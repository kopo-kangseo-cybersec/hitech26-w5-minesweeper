# 지뢰찾기

Windows 95 클래식 스타일로 만든 브라우저용 지뢰찾기 게임입니다. 별도 빌드 도구 없이 HTML 파일을 열어 실행할 수 있습니다.

## 게임 소개

초급, 중급, 고급 난이도에서 지뢰가 아닌 모든 칸을 열면 승리합니다. 첫 번째 칸과 주변 8칸에는 지뢰가 배치되지 않습니다.

## 어떻게 만들었나요

PRD에서 난이도, 첫 클릭 안전, chording, 승패 연출을 먼저 정의한 뒤 Vanilla JavaScript, HTML, CSS로 구현했습니다. 보드와 셀은 JavaScript에서 동적으로 생성합니다.

## freeform 버전과 비교했을 때

PRD 버전은 고정된 9 x 9 게임을 넘어 난이도 선택, 첫 클릭 안전, 중클릭/양손 chording, 컨페티와 상태 이모지를 포함합니다.

## 실행 방법

저장소에서 `index.html`을 브라우저로 직접 열면 됩니다. 서버나 패키지 설치는 필요하지 않습니다.

## 커스터마이징한 부분

- 초급: 9 x 9, 지뢰 10개
- 중급: 16 x 16, 지뢰 40개
- 고급: 30 x 16, 지뢰 99개
- 우클릭 깃발, 중클릭 및 양손 클릭 chording
- 3자리 지뢰 카운터와 최대 999초 타이머
- 승리 컨페티, 승패 상태 이모지, 모바일 가로 스크롤

자세한 실습 절차와 PRD 작성 흐름은 [guide.md](./guide.md)를 참고하세요.
