# 지뢰찾기

> 이 README는 게임을 완성한 뒤, 배포 직전 단계에서 작성합니다. 자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.

## 게임 소개

Windows 클래식 테마로 만든 싱글플레이 지뢰찾기입니다. 초급, 중급, 고급 난이도를 제공하며 첫 클릭 안전 규칙, 연쇄 열기, 깃발, chording을 지원합니다.

## 어떻게 만들었나요

PRD를 먼저 작성하고 구현 계획으로 분해한 뒤, HTML·CSS·Vanilla JavaScript 기반의 정적 웹 앱으로 구현했습니다. 게임 상태, 보드 렌더링, 입력 이벤트를 한 흐름으로 연결하되 첫 클릭 전 지뢰 배치를 지연해 안전 구역을 보장합니다.

## freeform 버전과 비교했을 때

freeform 버전은 기본 좌클릭·우클릭 게임 흐름에 집중하고, PRD 버전은 세 공식 난이도, 첫 클릭 안전, chording, 고전 UI, 승패 연출까지 명시적인 요구사항을 기준으로 구현합니다. 규칙과 화면 상태를 확인하기 쉬운 PRD 버전을 최종 기준으로 선택합니다.

## 실행 방법

저장소 루트에서 정적 서버를 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. `index.html`을 직접 열어도 기본 게임은 실행되지만, confetti CDN 사용을 위해 정적 서버 실행을 권장합니다.

## 커스터마이징한 부분

- Windows 95/98/2000 스타일 베벨 UI와 7세그먼트 느낌의 점수판
- 초급·중급·고급 고정 난이도 선택
- 첫 클릭 주변 8칸 안전 규칙
- 가운데 클릭과 좌·우 버튼 기반 chording
- 승리 confetti, 패배 시 지뢰·오표시 깃발 구분
- 반응형 보드와 키보드 포커스 접근성 처리
