# 💣 지뢰찾기

이 프로젝트는 클래식 지뢰찾기 게임을 PRD 기반으로 구현한 버전입니다. 초급, 중급, 고급 난이도를 선택할 수 있고, 첫 클릭 안전 규칙, 깃발 기능, 체인 열기, 타이머, 재시작 기능까지 기본적인 게임 흐름을 모두 포함합니다.

## 게임 소개

사용자는 격자 안에 숨겨진 지뢰를 피해서 모든 빈 칸을 열면 됩니다. 한 번도 신호가 없던 칸을 열면 숫자가 보이고, 주변에서 지뢰가 전혀 없으면 인접 빈칸들이 연쇄적으로 열립니다. 지뢰 위로 좌클릭하면 즉시 패배하며, 우클릭으로 깃발을 꽂아 실수를 줄일 수 있습니다.

## 어떻게 만들었나요

이 저장소는 PRD 문서를 기반으로 구현하는 흐름을 직접 따라가도록 구성했습니다. 먼저 요구사항을 문서화하고, 이후 구현 계획에 반영된 내용을 바탕으로 정적인 웹 게임을 만들었습니다. 난이도별 보드 설정, 안전한 첫 클릭, 승패 조건, 타이머와 재시작 기능을 모두 코드로 연결해 게임이 실제로 동작하도록 구성했습니다.

## freeform 버전과 비교했을 때

freeform 방식은 빠르게 기능을 만들 수 있다는 장점이 있지만, 기준이 부족하면 지뢰 생성 규칙, 타이머 동작, 난이도별 무결성 같은 핵심 요구사항이 누락되기 쉽습니다. 반면 PRD 버전은 게임 규칙을 먼저 정리해 두고 구현하니, 안전한 첫 클릭, 깃발 수 계산, 보드 크기와 지뢰 수의 일관성, 승패 조건 등을 더 안정적으로 맞출 수 있었습니다. 이 프로젝트에서는 PRD로 정리한 방식이 더 예측 가능하고 검증하기 쉬워 최종 선택했습니다.

## 실행 방법

로컬에서 바로 실행하려면 저장소 루트에서 다음처럼 열면 됩니다.

```bash
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 열면 게임이 실행됩니다.

## 커스터마이징한 부분

기본 예시보다 조금 더 완성도 있게 다음 부분을 다듬었습니다.

- 난이도별 보드 크기와 지뢰 개수 분리
- 첫 클릭 안전 규칙 적용
- 0 주변 연쇄 오픈 로직 추가
- 깃발 수와 타이머 HUD를 실시간 반영
- 재시작 버튼과 난이도 선택 UI를 포함한 게임 패널 구성

추가로, 설계상 커스텀 게임 모드, 최고 기록 저장, 물음표 마커는 제외하여 PRD 요구사항에 맞게 구현했습니다.
