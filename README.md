# 💣 레트로 스타일 지뢰찾기

## 게임 소개

이 프로젝트는 Windows 95/98 시절의 클래식 지뢰찾기 느낌을 웹에서 재현한 게임입니다. 3단계 난이도(초급/중급/고급), 좌클릭으로 타일 공개, 우클릭으로 깃발 배치, 지뢰 주변 숫자 표시, 첫 클릭 안전 보장, Chording, 승리/패배 연출을 포함합니다.

## 어떻게 만들었나요

이 프로젝트는 PRD를 기준으로 구현 흐름을 정리한 뒤, 상태 기반 로직과 레트로 UI를 결합해 완성했습니다. 먼저 보드 생성, 지뢰 배치, Flood Fill, 첫 클릭 안전 규칙과 승패 판정을 검증하는 순서로 로직을 구성했고, 그다음 메뉴 바, LED 카운터, 스마일 버튼, 메인 보드, 폭죽 효과를 CSS와 DOM 렌더링으로 이어 붙였습니다.

개발 프로세스는 다음처럼 진행했습니다.

- PRD 문서 작성
- 구현 계획 검토
- 테스트 기반 로직 검증
- 브라우저에서 실제 인터랙션 확인
- 레트로 UI 스타일 정리 및 최종 통합

## freeform 버전과 비교했을 때

freeform 버전은 빠르게 기능을 붙이는 데 초점을 두는 반면, 이 PRD 버전은 규칙의 정확성과 UX 완성도를 중시합니다. 특히 다음 항목이 크게 달랐습니다.

- 첫 클릭 안전 규칙을 보장하도록 지뢰 배치 로직 설계
- 좌클릭, 우클릭, Chording을 모두 고려한 상태 관리
- 게임 메뉴와 난이도 전환 기능
- 승리 시 컨페티, 패배 시 폭탄/잘못된 깃발 노출 연출
- 타이머와 남은 지뢰 카운터를 LED 스타일로 구현

이러한 이유로 PRD 기반 버전을 최종 선택했습니다. 단순히 동작만 하는 게임이 아니라, 클래식 지뢰찾기의 감성과 규칙을 체감할 수 있는 완성형 구현이라 판단했습니다.

## 실행 방법

로컬에서 바로 실행하려면 다음 명령을 사용하면 됩니다.

```bash
cd d:\repo\minesweeper
python -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 으로 접속하면 게임을 플레이할 수 있습니다.

테스트는 다음 명령으로 실행할 수 있습니다.

```bash
cd d:\repo\minesweeper
npm test
```

## 커스터마이징한 부분

- 난이도별 보드 크기와 지뢰 수를 데이터 객체로 분리
- 카운터와 타이머를 LED 스타일로 렌더링
- 고전 윈도우 버튼과 베벨 테두리로 레트로 UI 구성
- 승리 시 컨페티 애니메이션, 패배 시 지뢰 노출 연출
- 메뉴 드롭다운을 통해 난이도 변경 및 조작법 안내 추가

이 구현은 기본 지뢰찾기 규칙을 유지하면서도 실제 게임처럼 다루기 쉽게 설계되었습니다.
