## 실행 (GitHub Pages)

이 프로젝트는 GitHub Pages에 호스팅하도록 설계되었습니다. 로컬 서버 단계는 필수 사항이 아니며, 아래 중 한 가지 방법으로 GitHub Pages에 배포하면 바로 웹에서 플레이할 수 있습니다.

1) 간단한 설정(권장)
	- 변경사항을 커밋하고 원격 저장소에 푸시합니다:

		```bash
		git add .
		git commit -m "Add Minesweeper game"
		git push origin main
		```

	- GitHub에서 해당 리포지토리의 `Settings` → `Pages`로 이동합니다.
	- `Source`에서 브랜치(예: `main`)와 폴더(`/` 또는 `/docs`)를 선택한 뒤 저장합니다.
	- 설정이 반영되면 프로젝트 페이지는 보통 `https://<USERNAME>.github.io/<REPO>/` 형식의 URL에서 이용 가능합니다.

2) `gh-pages` 브랜치 사용
	- 정적 파일을 `gh-pages` 브랜치로 푸시하면 GitHub가 자동으로 배포합니다. 자동화가 필요하면 `gh-pages` npm 패키지 또는 `git worktree`를 활용하세요.

배포 후 제공된 URL로 접속하면 게임을 플레이할 수 있습니다.

- 안정성: 첫 클릭 안전 보장, chording 등 플레이 경험 개선
- UX: Windows 스타일 컨트롤(LED 카운터, 페이스 버튼), 난이도 선택
- 유지보수성: 파일 분리(`index.html`, `styles.css`, `app.js`) 및 명확한 로직 구조

따라서 배포/평가용으로는 이 PRD 기반 버전을 선택했습니다.

## 실행 방법
로컬 실행 방법:

1. 저장소를 클론하거나 압축을 풀어 프로젝트 루트로 이동합니다.
2. 브라우저에서 `index.html`을 직접 열면 됩니다. (간단한 정적 파일이므로 별도의 빌드 또는 서버가 필요하지 않습니다.)

권장: 일부 브라우저는 로컬 파일 보안 설정 때문에 기능 차이가 있을 수 있으므로 간단한 로컬 서버를 사용하려면 아래 중 하나를 실행하세요.

```bash
# Python 3
python -m http.server 8000

# 또는 Node.js 환경에서
npx http-server . -p 8000
```

그런 다음 브라우저에서 `http://localhost:8000/index.html`을 열어 플레이하세요.

## 추가된 구현 및 사용법

- 파일 구조
	- `index.html` — 게임 UI와 컨트롤(난이도 선택 포함)
	- `styles.css` — Windows 스타일의 레이아웃과 애니메이션
	- `app.js` — 게임 로직(그리드 생성, 지뢰 배치, 깃발, chording, 타이머, 승패 처리)

- 주요 동작
	- 좌클릭: 칸 열기
	- 우클릭: 깃발 토글(브라우저 컨텍스트 메뉴 비활성화)
	- 숫자 칸 클릭(이미 열린 칸): 주변에 꽂힌 깃발 수가 숫자와 같으면 주변 칸 자동 오픈(chording)
	- 중앙의 페이스 버튼: 리셋(초기화)
	- 상단 왼쪽 LED: 남은 지뢰(깃발 수로 계산)
	- 상단 오른쪽 LED: 경과 시간(첫 칸 오픈 시 시작)
	- 첫 클릭은 항상 안전하도록 지뢰 배치가 보장됩니다.

- 난이도
	- 초급(Beginner): 9×9, 10지뢰
	- 중급(Intermediate): 16×16, 40지뢰
	- 고급(Expert): 30×16, 99지뢰
	- 난이도는 상단의 드롭다운에서 변경 가능하며 변경 시 자동 리셋됩니다.

- 시각 효과
	- 승리 시 보드 및 카운터의 애니메이션(팡파레 대신 시각 효과)
	- 패배 시 보드 흔들림과 지뢰 펄스 애니메이션

- 제한 및 향후 개선
	- 현재 사운드는 제외하고 모두 시각 애니메이션으로 대체했습니다.
	- 모바일의 깃발 입력(롱프레스 또는 플래그 모드)은 아직 기본적으로 적용되지 않았습니다. 필요시 추가 구현 가능합니다.

## 실행
로컬에서 플레이하려면 저장소 루트의 `index.html`을 브라우저로 열면 됩니다.

GitHub Pages로 호스팅하려면 아래 방법 중 하나를 사용하세요.

1) 간단한 설정(권장)
	- 변경사항을 커밋하고 원격 저장소에 푸시합니다:

		```bash
		git add .
		git commit -m "Add Minesweeper game"
		git push origin main
		```

	- GitHub에서 해당 리포지토리 페이지로 가서 `Settings` → `Pages`(또는 `Pages` 섹션)을 엽니다.
	- `Source`에서 브랜치(예: `main`)와 폴더(`/` 또는 `/docs`)를 선택한 뒤 저장합니다.
	- 설정이 반영되면 프로젝트 페이지는 보통 `https://<USERNAME>.github.io/<REPO>/` 형식의 URL에서 이용 가능합니다.

2) gh-pages 브랜치 사용
	- 빌드 결과(여기서는 정적 파일)를 `gh-pages` 브랜치에 푸시하면 GitHub가 자동으로 배포합니다. 필요한 경우 `gh-pages` npm 패키지나 `git worktree`를 사용해 자동화할 수 있습니다.

참고: 프로젝트 페이지는 정적 파일만 필요하므로 별도의 서버 없이도 호스팅 가능합니다. 배포 후, 브라우저에서 제공된 URL로 접속하여 게임을 플레이하세요.
